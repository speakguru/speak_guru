      How Speak Guru works 🦉

      Designed for live, teacher-led Year 5 ESL speaking activities.

      1. Set up the class 👩‍🏫

      Create a class and add pupil names in My Classes. Pupils do not need accounts.

      2. Prepare questions 💭

      Choose one of six original missions or create your own questions, sentence starters and keywords.

      3. Start speaking! 🎤

      Choose a single-player mission or a friendly Speaking Battle. Run the timer while pupils speak aloud.

      4. Adjust the support 💡

      Show hints when needed and hide them to encourage spontaneous speaking.

      5. Award points 🏅

      Enter any score for each pupil based on their live performance. Both modes update the class total.

      6. Encourage everyone 🌈

      Celebrate effort and growth. Avoid using scores to embarrass pupils or increase speaking anxiety.

      Privacy & storage: This is a static GitHub Pages prototype. Pupil names, class groups, scores, and custom questions are stored in this browser only using local storage. They do not sync across devices, are not password-protected, and can be lost when browser data is cleared. Use first names or nicknames, avoid sensitive information, and use Export / Import for backups. This is not a secure school records system.
